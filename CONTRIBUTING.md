# Contributing

Thanks for helping! Issues and pull requests are welcome.

- **License.** Hevyfin is GPL-3.0-or-later. By sending a contribution you agree it's released
  under the same license, and that you have the right to contribute it.
- **No content, ever.** Don't add media, stream lists, indexer definitions, studio artwork,
  real broadcaster or studio logos, or anything you don't have the rights to. Test data uses
  made-up titles.
- **No personal data.** Don't commit server addresses, tokens, API keys, `android/key.properties`,
  keystores or screenshots of a real library with real people's names.
- **Tests.** `flutter test` and `cd browser && npm test` should pass. `flutter analyze` should
  stay clean.
- **Style.** Match the code around you: short comments that say *why*, plain names, Flutter's
  formatter (`dart format lib test`).
- **Windows / macOS help is very welcome**: neither is tested yet.
